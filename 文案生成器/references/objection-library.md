# Objection Library

Buyers doubt silently. They do not email; they leave. Every category has a short list of predictable doubts, and this skill's contract is to answer the real ones **honestly** — including when the answer is inconvenient ("it runs small").

## The universal nine

Check these on every product before touching the category list.

| Doubt | What it sounds like | How to answer |
|---|---|---|
| Price / value | "Why is this 3× the other one?" | Name what the extra money buys, in the buyer's units (years, washes, servings) |
| Fit / size | "Will this work for me specifically?" | Give the number, the measurement anchor, and the recommendation between sizes |
| Durability | "How long before it breaks?" | Warranty, cycle rating, or material — a source number, never a feeling |
| Compatibility | "Does it work with mine?" | List the exact models/specs, and say what it does *not* fit |
| Effort | "Is this a project?" | Count steps, tools, minutes |
| Returns | "What if I hate it?" | State the window and who pays return shipping if known |
| Smell / allergen / irritation | "Will this bother me?" | Name the free-from list from the source; never claim "safe for all skin" |
| Stock / shipping | "Can I get it in time?" | Only if logistics data exists. Otherwise omit — do not estimate |
| The cheap-alternative trap | "Isn't this the same as the $9 one?" | Name the one difference that changes the outcome |

## Category lists

### Apparel & footwear
- **Runs small / large.** State it directly and give the rule: "Between sizes? Take the larger — the shoulders are cut close."
- **Fabric feel and shrinkage.** First-wash behaviour if the care label implies it.
- **Opacity / sheerness.** A real reason for returns.
- **Season mismatch.** Which temperature range it is actually for.

### Home & kitchen
- **Counter / cabinet footprint.** Give height with lid or handle, not just the body.
- **Heat limitations.** Max temperature, and whether it is stovetop, oven, or induction safe.
- **Noise and vibration.** For anything with a motor.
- **Cleaning reality.** Dishwasher-safe in which parts, and what needs hand washing.

### Electronics & accessories
- **Will it work with my device.** Version, port, protocol, OS floor.
- **Real battery life.** Distinguish rated vs realistic, and say which is which.
- **Latency / lag.** Only if the source has a number.
- **Heating or bulk.** Physical annoyances the spec sheet hides.
- **Setup friction.** Account required, app required, pairing steps.

### Beauty & personal care
- **Will it break me out / sting.** Say the formula's known irritants if the source lists them.
- **White cast, pilling, greasiness.** Texture honesty beats texture adjectives.
- **How long does it last.** In applications or weeks, from the size.
- **Is it a medical product?** Never. Route to compliance doc — do not answer this one in copy.

### Food & consumables
- **Taste and texture.** What the source actually states. Never invent flavour notes.
- **Portioning.** How many servings per pack, in cups or pieces.
- **Shelf life and storage.** Opened vs unopened.
- **Allergen presence.** Use the source's allergen statement verbatim; if absent, flag it as missing rather than guessing.

### Tools & hardware
- **What's in the box.** Missing-anything is the top return driver.
- **Power and duty cycle.** Continuous or intermittent.
- **Material fatigue point.** What actually wears out first.
- **Learning curve.** One line on the first project.

### Furniture & large goods
- **Will it fit through my door / in my lift.** Assembly dimensions, not just assembled.
- **Assembly difficulty.** Two people? Tool included?
- **Sturdiness and weight rating.** Source number only.
- **Colour accuracy.** Natural materials vary — say so if the source says so.

### Pet & baby
- **Safety.** Only source-backed statements. Absolute rigidity here; see compliance.
- **Size to age / breed / weight.** Give the ranges explicitly.
- **Cleanability.** The number one purchase blocker in this category.

## Placement rules

1. **Top three doubts** go inside the benefit bullets, one clause each — that is where the decision happens.
2. **The rest** go in a short **"Good to know"** block, 2–4 lines, one line per doubt.
3. **Never** answer an objection with a superlative. "Highest quality" answers nothing.
4. If a doubt has no honest answer from the source, **say the source is silent** and ask the user for the fact. Do not soften it.
5. If the product is genuinely worse on a dimension buyers will notice, **say it in the Details block** and frame who it is *not* for. This converts better than a refund.

## Lines that must never appear

- "True to size!" when the source or return data says otherwise.
- "One size fits all."
- "Safe for all skin types."
- "You won't even notice the difference."
- "Barely any assembly required."
- Any fabricated review, rating, or "customers love…" line — testimonial claims need a real, permissioned quote.
